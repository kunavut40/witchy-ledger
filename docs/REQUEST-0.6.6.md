# ข้อกำหนดฉบับปรับ 0.6.6

พัฒนา Witchy Ledger ต่อจาก 0.6.5 โดยคงข้อมูลบัญชีเดิมและเกณฑ์ progression จริง

- ฟอร์มเปิดโดยไม่ focus เงินอัตโนมัติ ช่องใหม่ placeholder 0 ไม่มี .00 บังคับ ข้อมูลเก่าที่มีสตางค์ต้องไม่ถูกปัดทิ้ง
- เพิ่มหมวดมาตรฐานแบบ migration ที่ไม่ลบ ID เดิมหรือทับ icon ที่ผู้ใช้เลือกเอง มีค่าสาธารณูปโภค สุขภาพ การศึกษา ช้อปปิ้ง สื่อสาร สัตว์เลี้ยง ของขวัญ ภาษี และหมวดย่อย
- ไอคอน potion สำหรับกาแฟ ชา น้ำ เครื่องดื่ม แยกรูป/สี ธนาคารเป็นคริสตัลเปลี่ยนแสงตามธีม เงินสดเป็นหีบเปิดฝามีเหรียญและดาวทอง
- ทุกวงกดค้างใช้ดาวและหางแสงสีตามธีม ไม่มีเส้นเชื่อมเมนู วงหมวดย่อยล่างสุดเป็นย้อนกลับเสมอ โดยไม่แก้หมวดที่เลือก
- เปลี่ยนฉากเข้า/ออกฟอร์มด้วยลม ใบไม้ และ fade ย้อนทิศกัน ปิด animation เมื่อเปิด reduced motion
- ตารางเรียงรายการ วันที่ จำนวนเงิน บัญชี และปุ่มจัดการ วันที่ชิดรายการขึ้น
- ส่วนหัวเพิ่มรูปตัวละคร ตกแต่งเส้นดาวและแถบ XP ตามตัวอย่าง
- โหมดทดสอบปลดล็อกของและกรอบ rank ทุกระดับ โดยไม่แก้ XP หรือยอดเงินจริง และมี toggle กลับโหมดปกติ
- ตู้แต่งตัวเป็นฉากห้องพิกเซลและแผงชุดเหมือนภาพอ้างอิง ใช้ภาพแยกเลเยอร์จริง ชุด 8 แบบ ทรงผม 5 แบบสำหรับยูอิ/โมโมะ และเครื่องประดับ 8 แบบ เปลี่ยนแล้วผลต้องปรากฏที่ตัวละครจริงและจำหลังเปิดใหม่
- รักษาตัวเลือก legacy ผ่านการจับคู่รูปลักษณ์ใกล้เคียง แสดงเฉพาะรายการที่มีภาพรองรับในตู้ ไม่ทำตัวเลือกหลอก
- แสงหน้าต่าง ลูกแก้ว นาฬิกาทราย คริสตัล และโคมไฟมี animation แสงธีม
- ผู้ช่วยคุยเมื่อเข้าแอปและหลังบันทึกรายรับ/รายจ่ายใหม่ ข้อความต้องอิงรายการที่บันทึกจริง
- ตรวจ rig ที่จุดต่อคอ ใบหน้า หมวก แว่น และการซ้อนภาพทุกชุด รวม alpha และความไม่ซ้ำของภาพ ไม่ถือว่าชื่อปุ่มเปลี่ยนเป็นหลักฐานว่าภาพเปลี่ยน
- บิลด์ APK ที่ใช้ package/key เดิมของ 0.6.4–0.6.5 เพื่ออัปเดตทับและรักษาข้อมูล เก็บผลทดสอบและข้อจำกัดตรงตามจริง
