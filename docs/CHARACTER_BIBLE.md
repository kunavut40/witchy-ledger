# Witchy Ledger character bible

## ยูอิ / Yui

ผู้ช่วยสมุดบัญชีเวทมนตร์ บุคลิกซึนเดเระ: จริงจัง ปากแข็ง แต่ห่วงใย ชอบความสม่ำเสมอ ชอบแซวกาแฟ และเขินเมื่อได้รับคำชม ใช้ภาษาไทย เรียกผู้ใช้ว่า “เธอ” หรือเว้นประธาน ลงท้ายอย่างเป็นธรรมชาติ เช่น “ล่ะ”, “สิ”, “หรอก”, “ต่างหาก” ไม่พูดเหมือนระบบธนาคาร ไม่ดุด่าหรือทำให้รู้สึกผิดกับค่าใช้จ่ายจำเป็น

ใบหน้าอิงไอคอนแอพ ผมดำอมพลัม ตาดำ หันไปทางขวาของหน้าจอเล็กน้อย งาน Detailed 2D Pixel Art / Dark Cozy Fantasy / Witch Academy การเปลี่ยนชุดไม่เปลี่ยนบุคลิก

ผู้ใช้เดิมเก็บชุดที่เลือกไว้ ผู้ใช้ใหม่เริ่มชุดนักเรียนเวทมนตร์ (`outfit: 1`) ไม่มีหมวกโดยอัตโนมัติ ชุดขาวเดิมยังเลือกได้

## โมโมะ / Momo

รักษาชื่อ ภาพผมชมพู และบุคลิกขี้เล่น มีคลังบทพูดเฉพาะ ไม่ยืมคำพูดซึนเดเระของยูอิเป็นค่าเริ่มต้น กิ๊บหัวกะโหลกเป็นเครื่องประดับเริ่มต้นเมื่อเลือกโมโมะครั้งแรก รูปลักษณ์ของแต่ละคนจำแยกกัน

## กฎข้อมูล

- บอกจำนวนแก้วหรือผู้รับเฉพาะที่ระบุจริง ไม่เดาจากยอดเงินหรือจำนวนธุรกรรม
- เตือนงบเฉพาะเมื่อมีงบและเข้าเงื่อนไขจริง ไม่ใช้ประโยคใกล้เต็มงบกับรายการทั่วไป
- ไม่อ้างว่ามีรางวัลถูกมอบ ถ้าระบบเดิมไม่ได้มอบรางวัลนั้น
- ไม่เปลี่ยนยอดเงิน เกณฑ์แรงก์ XP หรือข้อมูลบัญชีจากบทพูด
- บทพูดอยู่ใน `src/fantasy/dialogueBank.json`; trigger อยู่ใน `events.ts` และ `engine.ts`
- บทคุยตามความสนิทอยู่ใน `affinityDialogue.json` แยกห้าระดับ คนละห้าบรรทัดต่อระดับ ไม่ย้ายข้อมูลการเงินตามระดับความสนิท

## ความสนิท

แยกตัวละคร แยกจากแรงก์การเงิน ได้สูงสุดหนึ่งแต้มต่อวันต่อคนจากการเปิดแอพ คุย หรือบันทึกตามจริง ไม่เพิ่มตามจำนวนเงิน ไม่หักเมื่อไม่ได้เข้าแอพ

| แต้ม | ระดับ | พฤติกรรม / สิทธิ์แต่งตัวเพิ่มเติม |
| --- | --- | --- |
| 0 | ยังไม่สนิท | พูดตรง รักษาบุคลิกเดิม |
| 7 | เริ่มคุ้นเคย | เข้าถึงชุดนอนกระต่ายและทรงผมเพิ่ม |
| 21 | เพื่อนสนิท | เข้าถึงทรงผมเพิ่ม |
| 60 | ไว้ใจ | บทพูดอ่อนโยนเพิ่มเติมในอีเวนต์ที่เหมาะสม ชุดโกธิก |
| 120 | คู่หูสมุดเวท | กิโมโนและทรงผมครบ โดยยังซึนเดเระ |

สิทธิ์ความสนิทเป็นทางเลือกเพิ่มเติม ไม่ปิดสิทธิ์ที่เลเวลเดิมหรือโหมดทดสอบอนุญาตอยู่แล้ว

ประวัติบทพูดแยกคนเก็บ 250 บรรทัดล่าสุดและสามบรรทัดล่าสุดเพื่อหลบการพูดซ้ำ ประวัติคีย์ที่รับไปแล้วเก็บแยกถาวร ไม่ล้างเมื่อเปลี่ยนชุด
