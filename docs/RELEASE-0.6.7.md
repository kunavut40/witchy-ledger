# Witchy Ledger 0.6.7 local test

This update continues from v0.6.3-local-test and includes the accumulated UI, fantasy artwork, radial entry, calendar, and wardrobe improvements.

## Latest fixes

- Shorter character neck and aligned hair, hats, glasses, and accessory anchors.
- Preset selection shows the leaf transition only after saving. Manual entry fades and blurs the background, then slides in; saving reverses the transition.
- Yui responds to income and expense saves, including after the companion was hidden.
- Modular wardrobe with eight outfits, five hairstyles per character, and eight accessory options. Test unlock does not change money or XP.
- Fantasy category icons, animated account selectors, rank frames, themed calendar, weekly income/expense bars, and bottom navigation improvements.

## Validation

- 41 automated tests passed across nine test files.
- TypeScript check and production web build passed.
- Browser checks covered mobile layouts, wardrobe changes and persistence, radial entry, calendar selection, transitions, and companion events.
- Android APK built and signature verified. Installation, audio, and touch behavior still need testing on a physical phone.
