## เปิดใช้งานฉบับพร้อมใช้

ต้องมี Node.js 22 หรือใหม่กว่า (เครื่องที่พัฒนาใช้ Node 24) มี `dist/` ที่ build แล้วแนบมาด้วย ไม่ต้องติดตั้ง dependencies เพื่อทดลองฉบับนี้

1. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `node serve.mjs` หรือดับเบิลคลิก `Start.cmd` บน Windows
2. เปิด http://127.0.0.1:4173 ในเบราว์เซอร์ และคงหน้าต่าง Terminal ไว้
3. เริ่มด้วยข้อมูลว่าง หรือไป ตั้งค่า → เพิ่มข้อมูลตัวอย่าง
4. เปิดหน้าครั้งแรกขณะ server ทำงาน รอให้ service worker แคชแอป หลังจากนั้น refresh บน browser/URL เดิมได้แม้ server หยุด

ใช้ URL เดิมเสมอ: localhost, 127.0.0.1 และแต่ละ port มีฐานข้อมูลคนละชุด ห้ามเปิด index.html ด้วย file://

หากขึ้น `'node' is not recognized` ให้ใช้ Start.cmd ฉบับแก้ไข ซึ่งค้นหา Node.js จาก PATH, โฟลเดอร์ติดตั้งทั่วไป และ runtime ของ Codex ในเครื่องนี้โดยอัตโนมัติ ไม่ต้องตั้ง PATH เอง หากใช้เครื่องอื่นที่ไม่มี Node.js ต้องติดตั้ง Node.js 22 หรือใหม่กว่าก่อน

## ใช้งานได้แล้ว

- Dashboard จาก IndexedDB: ยอดเงินสะสมถึงวันสิ้นรอบ รายรับ รายจ่าย ยอดสุทธิ กราฟหมวดและรายวัน งบประมาณ เงินออม หนี้ และรายการล่าสุด
- เพิ่ม แก้ไข ลบ ค้นหา กรองประเภท/บัญชี/หมวด และเรียงรายการ เลือกดูทุกรอบได้
- หมวดหลัก/ย่อย: สร้าง เปลี่ยนชื่อ สี ไอคอน ลำดับ ย้ายกลุ่ม และ archive อ้างอิงด้วย ID
- บัญชีเงินสด ธนาคาร e-wallet ออมทรัพย์ บัตรเครดิต หนี้ และอื่น ๆ เปิด/พักบัญชีได้
- ยอดเริ่มต้น และรายการปรับยอดที่เก็บประวัติ เมื่อมีรายการแล้วจะล็อกยอดเริ่มต้นและประเภทบัญชี
- รอบเงินเดือน/เดือนปฏิทิน/กำหนดเอง สร้าง เปลี่ยนชื่อ แก้ช่วง ดูย้อนหลัง clone รอบถัดไป และเตือน overlap/gap
- งบประมาณต่อรอบ พร้อมยอดใช้จริงและเตือนเกินงบ
- เป้าหมายออมผูกบัญชีออมทรัพย์ (ควรแยกบัญชีต่อเป้าหมาย)
- ซื้อด้วยบัตรเป็นรายจ่ายและเพิ่มหนี้ ชำระบัตร/หนี้ใช้โอนจากบัญชีเงิน ไม่เพิ่มรายจ่ายซ้ำ
- JSON backup พร้อมตรวจไฟล์/preview/ยืนยันก่อน restore และ CSV export รายการทั้งหมด
- Responsive sidebar/bottom navigation, ฟอนต์ไทยใน bundle, ไอคอน SVG pixel ต้นฉบับ, service worker สำหรับ offline

## ตรรกะและข้อควรทราบ

- จำนวนเงินเก็บเป็น integer สตางค์ ไม่ใช้ float เป็นฐานคำนวณ
- ISO date เก็บเฉพาะวัน (`YYYY-MM-DD`) เปรียบเทียบช่วงแบบรวมวันเริ่ม/สิ้นสุด วันที่รายงานใช้ th-TH พ.ศ. และ UTC เพื่อไม่เลื่อนวัน
- Actual balance รวมบัญชีสินทรัพย์ทุกบัญชี (รวมบัญชีพักใช้งาน) ถึงวันสิ้นรอบ ไม่หักหนี้ ส่วนหนี้แสดงแยกต่างหาก
- Period cash flow = รายรับ − รายจ่ายของรอบ ไม่รวมโอน/ปรับยอด การชำระหนี้จึงลดเงินจริงแต่ไม่ลด cash flow ซ้ำ
- ยอดเริ่มต้นมีผลก่อนธุรกรรมทั้งหมด ไม่มีวันที่เริ่มบัญชีใน Phase 1
- Clone ใช้จำนวนวันเท่ารอบก่อนและเริ่มวันถัดไป ผู้ใช้แก้วันสิ้นสุดให้ตรงวันเงินเดือนจริงได้
- กราฟรายวันแสดงวันที่มีธุรกรรมในรอบ วันว่างไม่ได้แสดงเป็นจุดศูนย์
- หมวดเก็บถาวรยังรวมในรายงานและข้อมูลย้อนหลัง การลบถาวรของหมวดไม่เปิดให้ใช้งาน
- สำรอง JSON รองรับ schema version 1 และแทนที่ข้อมูลใน transaction เดียว ห้ามใช้ CSV เพื่อ restore ทั้งระบบ
- มี schema สำรองสำหรับ liabilities, creditCardStatements, scheduledTransactions, backupMetadata, liabilityPayments, importHistory แต่ยังไม่มีฟังก์ชันเขียนข้อมูลลงตารางเหล่านี้ Backup ปัจจุบันครอบคลุม 7 ตารางที่ใช้จริง

## ความเป็นส่วนตัว

ไม่มี backend, login, telemetry, AI cloud, API key หรือ cloud sync ข้อมูลเก็บใน IndexedDB ของ browser profile นี้ทั้งหมด ฟอนต์และ dependencies เสิร์ฟจากเครื่อง แอปไม่เปิดไมค์เอง ช่องกรอกมาตรฐานรองรับ dictation ของคีย์บอร์ด ซึ่งนโยบายการประมวลผลเสียงขึ้นกับคีย์บอร์ด/อุปกรณ์

ล้างข้อมูลเว็บไซต์/เปลี่ยน browser profile อาจทำให้ข้อมูลหาย สำรอง JSON เป็นระยะ โดยเฉพาะก่อนย้ายเครื่อง ไฟล์สำรองเป็นข้อความธรรมดาที่มีข้อมูลการเงิน ควรเก็บไว้ในพื้นที่ส่วนตัวของคุณ

## โครงสร้าง

`src/domain.ts` types และฟังก์ชันคำนวณบริสุทธิ์, `src/db.ts` repository และ Dexie schema/migration/backup, `src/App.tsx` หน้าจอและฟอร์ม, `src/Pixel.tsx` ไอคอนเปลี่ยนภายหลังได้, `src/style.css` responsive theme การเปลี่ยน repository เป็น SQLite ทำได้โดยคง domain model เดิมและแทนที่การอ่าน/เขียนฐานข้อมูล

ทดสอบด้วย Vitest + fake-indexeddb รวม 12 กรณี: CRUD, persistence เมื่อเปิดฐานข้อมูลใหม่, เปลี่ยนชื่อ/ย้ายหมวด, รอบข้ามเดือนและปี, ยอดสะสม, โอนออม, เครดิต/ชำระบิลไม่ซ้ำ, ปรับยอด, validate, backup/restore และไฟล์เสีย ทดสอบผ่านเบราว์เซอร์เพิ่มเติมสำหรับ refresh และรูปแบบหน้าจอ ดูผลตรวจล่าสุดใน QA.md
